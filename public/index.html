02

What is the JEV AI Model?

TypeSafe AI's System One model speaks in decisions, not paragraphs.

⟠

Decisions, not strings

Choice selects a label, Score returns an expected rubric position, and Noul returns a yes-probability. Score values may be fractional.

⩆

Probability and confidence

Choice and Score expose distributions and confidence. Noul exposes a yes-probability. These are different signals; evaluate them on your own data.

∵

Typed outputs can still be wrong

A constrained answer can be incorrect. Include a review path, test representative cases and monitor errors.

✢

Your code decides when to act

Validate answers and set thresholds in application code. Use fallback logic when the evidence is uncertain.
