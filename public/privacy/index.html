Privacy Policy

JevHunt is a public directory. You can browse every listing without creating an account. Google sign-in is optional and is used only when you submit a project.

Last updated: September 21, 2026

We never receive your Google password, JEV API keys, source-code credentials or payment details. Do not send those values through the submission form.

Information we process

  • Public browsing: no JevHunt account is required.
  • Google sign-in: Google provides a stable account identifier, name, email address and optional profile image after you approve the OAuth screen.
  • Sessions: JevHunt stores only a hash of the session token, plus limited security metadata such as IP address and user agent. Session cookies are HttpOnly, Secure and SameSite=Lax.
  • Submissions: project name, public URL, category and description, along with submission status and time.
  • Analytics: Google Analytics 4 may process page views, device and browser information, approximate geography and interactions. JevHunt does not intentionally send form contents, email addresses or API keys to Analytics.

Why we use it

We use account data to authenticate submitters, prevent abuse, show each user their own submissions and communicate submission status. We use aggregate analytics to understand which pages and directory features are useful. Security metadata is used to protect accounts and investigate misuse.

Service providers

Cloudflare hosts the site, Pages Functions and D1 database. Google provides OAuth sign-in and Google Analytics 4. These providers process data under their own terms and privacy policies. JevHunt does not sell personal information.

Retention and choices

OAuth state records expire after 10 minutes and sessions expire after 30 days. Account and submission records remain while needed to operate the directory, review submissions and prevent abuse. You can browse without signing in, sign out at any time, block analytics with browser controls, or request deletion of your account and submissions.

External links

Catalog links go only to public GitHub repositories and README evidence. JevHunt does not control third-party repositories, so review their source, releases, permissions and policies before using them.

Questions and deletion requests

Start a request through the JevHunt GitHub issue tracker without posting personal information. A maintainer will provide a private verification path when identity confirmation is required.
